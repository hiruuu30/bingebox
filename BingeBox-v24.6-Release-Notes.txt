BingeBox v24.6 — Player Interaction + Landscape + Workspace + Episode Count

PLAYER
- Rebuilt hold-to-2x gesture so the shell captures the hold reliably, not only the video element.
- Release, cancellation, app blur, pause and visibility changes force playback back to normal 1x.
- Added a contextual landscape button that appears only for landscape direct video.
- Landscape control uses fullscreen/orientation lock where supported with iOS video-fullscreen fallback.

HOMEPAGE

WORKSPACE

- Reduced oversized headings, tightened density, improved visual hierarchy, refined library rows and controls, and kept all existing IDs/actions intact.

CACHE
